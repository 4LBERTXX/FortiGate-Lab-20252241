# FortiGate-Lab-20252241
Propósito del laboratorio

Este laboratorio implementa una topología de red segura con FortiGate como firewall perimetral, protegiendo un WEB-Server y un DB-Server mediante políticas de firewall, segmentación por VLANs, Deep Packet Inspection con detección/bloqueo de SQL Injection (con cuarentena del atacante), restricción de tráfico entre servidores al puerto necesario, filtrado de descargas .exe y rate limiting contra ataques DoS.
